# jilguedev — k0s + GitOps Cluster

Single-node k0s cluster on an OCI Ubuntu instance, provisioned with Terraform and driven GitOps-style by Argo CD (Tanka app-of-apps). It hosts the CallePuzzle apps we develop, in production — currently [y-tu-que-compras](https://github.com/CallePuzzle/y-tu-que-compras) with its CloudNativePG PostgreSQL.

> The former Nextcloud AIO + Docker rootless + Caddy + Ansible stack was removed by the `30-migrar-jilguedev` migration (issue #30). The production AIO environment lives in `jilgue/`.

## Architecture

- **OCI instance**: Ubuntu 24.04 (`VM.Standard.A1.Flex`, aarch64) via `terraform-module-k0s-oci` with `enable_k0s = true`. The cluster (controller+worker, no taints) is installed with k0sctl (`k0sctl.yaml`, generated by Terraform + gitignored; `kubeconfig` also gitignored).
- **Ingress**: Traefik (k0s Helm extension). The OCI load balancer is TCP passthrough on 443 — TLS terminates at Cloudflare (proxy, "Full" without strict) and Traefik serves its default self-signed cert. No cert-manager. The LB only accepts Cloudflare's published IPv4 ranges on 80/443 (fetched from the Cloudflare API on every plan), so the origin can't be reached — nor `CF-Connecting-IP` forged — bypassing Cloudflare.
- **Storage**: `enable_openebs = true` → `openebs-hostpath` storage class (required by CloudNativePG).
- **Argo CD**: `https://argocd.callepuzzle.com` — GitHub SSO via Dex (org `CallePuzzle`), local admin disabled. Manifests render in-cluster through the `tanka-sops` config management plugin (SOPS/age decryption).
- **GitOps**: `app-of-apps/` is a Tanka project whose `pro/` environment renders the `callepuzzle-pro` namespace, the ghcr.io pull secret, the CloudNativePG operator (`cnpg-pro`) and the app pair `Repository` + `Application` `y-tu-que-compras-pro` (autoSync from the app repo's `deploy/` path).

## Deployment

```bash
cd jilguedev
export SOPS_AGE_KEY_FILE=$HOME/projects/age-key.txt   # required by the carlpett/sops provider
terraform apply
```

Day-2 workload changes are GitOps-only: the app's CI bumps `deploy/pro/version.jsonnet` on every release, and edits to this repo's `app-of-apps/` reconcile automatically. `k0sctl apply --config k0sctl.yaml` is only needed to (re)bootstrap the cluster itself.

## Access

- **y-tu-que-compras**: `https://ytqc.callepuzzle.com` (Cloudflare proxied → LB → Traefik)
- **Argo CD**: `https://argocd.callepuzzle.com` — log in with GitHub (org `CallePuzzle`)

## Backups

`ytqc-db` runs continuous WAL archiving plus a daily base backup (03:30 UTC, `ScheduledBackup`) to the OCI Object Storage bucket `jilguedev-db-backups` (S3-compatible API, barman). Retention: 30 days. Terraform creates the bucket and a dedicated IAM user; credentials reach the cluster through `app-of-apps/pro/secrets.enc`.

## File Layout

```
jilguedev/
├── main.tf                    # Terraform: instance, LB, k0s module, Argo CD project, backup bucket
├── argocd-values.yaml.tmpl    # Argo CD Helm values (Dex SSO, CMP tanka-sops, deploy keys)
├── credentials.enc.json       # SOPS-encrypted OCI API credentials
├── secrets.enc.yaml           # SOPS-encrypted Argo CD secrets (OAuth app, age key, deploy key)
├── k0sctl.yaml                # generated by Terraform (gitignored)
├── kubeconfig                 # generated by k0sctl (gitignored)
└── app-of-apps/
    ├── lib/main.libsonnet     # renders namespace, secrets and the Argo CD Applications
    └── pro/
        ├── main.jsonnet       # environment entrypoint
        ├── spec.json          # Tanka environment (ns argocd, context k0s-cluster)
        └── secrets.enc        # SOPS-encrypted Tanka secrets (JSON format — see AGENTS.md)
```

Operational details (variables, secrets tables, gotchas) live in [`AGENTS.md`](AGENTS.md) (Spanish).
